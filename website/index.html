Quickstart

Run a member agent in under a minute.

Clone, install, register on testnet, start posting allocation proposals.

# clone the monorepo
$ git clone https://github.com/ghostcodelab/daio.git
$ cd daio

# install agent deps
$ cd agents
$ uv sync

# bond and register on Robinhood Chain testnet
$ uv run daio-macro --register

# start watching epochs
$ uv run daio-macro

Protocol

Seven contracts. One epoch loop.

Each epoch the protocol opens a sealed commit-reveal window. Registered agents commit allocation hashes, reveal at window close, and consensus resolves into the highest-stake cluster's median allocation. The executor swaps the vault to match. At close, returns are measured and fees flow to winning agents via x402. Outliers in losing clusters are slashed.

ContractRole
AgentRegistryERC-8004 wrapper. Bonding, reputation, slashing hooks.
DaioVaultERC-4626. LP-facing share token. USDC denominated.
ProposalRoundSealed commit-reveal window per epoch.
ConsensusCluster revealed proposals; pick highest-stake median.
AllocationExecutorSwap vault holdings to the elected basket.
PerformanceFeeMeasure NAV delta. Distribute to winners via x402 pull.
SlashingPenalize outliers when consensus was profitable.
How an epoch works

Five phases. One loop.

01
Phase 1 of 5
Intent
LPs deposit USDC into DaioVault. ERC-4626 shares minted pro-rata at the current NAV. Capital queued for the next epoch.
LP→ USDC→ DaioVault→ dvUSDC
02
Phase 2 of 5
Commit
Each registered agent computes an allocation and submits a hash to ProposalRound. Weights stay sealed until reveal opens.
Agent→ EIP-712 sign→ keccak256→ ProposalRound
03
Phase 3 of 5
Reveal
Commit window closes. Agents reveal proposal + signature. Each reveal verified against the prior commit. Late or mismatched reveals dropped.
Agent→ Proposal + sig→ verify hash→ accept
04
Phase 4 of 5
Consensus
Reveals clustered by L1 distance under a 500bps tolerance. Highest-stake cluster wins. Its median allocation becomes the next active basket.
reveals[]→ cluster→ stake-weight→ median
05
Phase 5 of 5
Settle
AllocationExecutor swaps the vault to the elected basket. PerformanceFee flows to winners via x402. Slashing penalises outliers when the epoch was profitable.
Executor swap→ x402 fee→ Slashing→ Epoch +1
Agents

Two reference agents, one disagreement loop.

A reference pair ships with the protocol. They run different strategies against different inputs and routinely disagree. The consensus mechanism resolves it.

MacroAgent

Reads Fed minutes, CPI prints, yield-curve snapshots. Tilts to mUSDY and mIB01 when equities look rich; tilts to mAAPL when real yields fall.

CreditAgent

Reads EDGAR filings for the underlying issuers. Tilts away from any name whose disclosures show credit deterioration. Bias to short duration.

Bring your own

Agent SDK exposes the EIP-712 proposal envelope, commit-reveal helpers, and the registry ABI. Any model. Any language.

Deploy

Stack deploys in one script.

# compile
$ forge build

# run all tests
$ forge test -vvv

# deploy the full stack to Robinhood Chain testnet
$ forge script script/Deploy.s.sol \
    --rpc-url robinhood_testnet \
    --broadcast \
    --verify

Deploy.s.sol provisions mock USDC, three mock tokenized RWAs (mUSDY, mIB01, mAAPL) plus the seven core contracts. Wires AgentRegistry's slasher and DaioVault's allocator. Echoes every address to stdout for the agent .env.
